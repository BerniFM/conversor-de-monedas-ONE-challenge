# conversor-de-monedas-ONE-challenge
En este desafío, se desarrolló un conversor de monedas en Java utilizando la API de ExchangeRate-API.

Programa utilizado: Intellij IDEA
La solución fue implementada en Java, utilizando la API de ExchangeRate para obtener los datos actualizados del tipo de cambio de las monedas.

Para la solucion se crearon 3 packages :
  1.calculos
    consultarMoneda
    convertirMoneda
  2.moneda
    monedas
  3.principal
    principal

Al iniciar el programa se muestra un menu como el siguiente:
